# 🦖 Proyecto: “¿Qué dinosaurio sería mejor mascota?”

### 🎯 Objetivo

Desarrollar un dashboard que permita analizar distintas especies de dinosaurios y determinar cuáles serían las más adecuadas para ser mascotas, considerando características como **tamaño, alimentación, agresividad, velocidad, peso y período histórico**.

El usuario podrá explorar los dinosaurios desde una vista general hasta el detalle de cada especie y consultar un **Índice de Mascotabilidad** que determine si un dinosaurio sería una mascota recomendable, poco recomendable o directamente una pésima idea.

---

## 🗃️ Las 4 entidades

Acá tenemos que pensarlo para que sean entidades reales y relacionadas:

### 1. 🦖 Dinosaurio

* id_dinosaurio
* nombre
* altura
* longitud
* peso
* velocidad
* nivel_agresividad
* inteligencia
* expectativa_vida

### 2. 🌿 Alimentación

* id_alimentacion
* tipo: herbívoro / carnívoro / omnívoro
* consumo_diario_estimado
* dificultad_de_alimentación

### 3. 🌎 Hábitat

* id_habitat
* nombre
* clima
* superficie_necesaria
* vegetación

### 4. ⏳ Período

* id_periodo
* nombre
* era
* millones_de_años_inicio
* millones_de_años_fin

Así tenemos relaciones del estilo:

**Período → Hábitat → Dinosaurio → Alimentación**

Y podemos usar esas relaciones para el Drill Down.

# 🚦 La parte más divertida: semaforización

Podemos crear un **Índice de Mascotabilidad (IM)** de 0 a 100.

Por ejemplo:

🟢 **Verde — 70 a 100**

> “Podría ser una mascota razonable.”

🟡 **Amarillo — 40 a 69**

> “Requiere bastante preparación.”

🔴 **Rojo — 0 a 39**

> “Se recomienda reconsiderar la idea.”

El índice podría calcularse utilizando:

* tamaño
* agresividad
* alimentación
* velocidad
* espacio requerido
* dificultad de cuidado

Entonces podés tener una tarjeta enorme:

### 🦖 ÍNDICE DE MASCOTABILIDAD

**23 / 100 🔴**

> **Nivel de riesgo: CRÍTICO**

Eso cumple perfectamente con la parte de semaforización.

# 🧮 Y SQL da para bastante

Podés hacer consultas como:

```sql
SELECT 
    tipo_alimentacion,
    AVG(peso) AS peso_promedio
FROM dinosaurios
GROUP BY tipo_alimentacion;
```

O:

```sql
SELECT 
    nombre,
    indice_mascotabilidad
FROM dinosaurios
ORDER BY indice_mascotabilidad DESC
LIMIT 10;
```

Y consultas para cada nivel del Drill Down.
