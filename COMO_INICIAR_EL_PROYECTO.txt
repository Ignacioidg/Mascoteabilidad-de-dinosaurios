--------------------------------------------------------------------
OPCIÓN A: EN TU COMPUTADORA ACTUAL (USO DIARIO)
--------------------------------------------------------------------
Como ya tienes todas las dependencias de Python instaladas, solo haz:

Paso 1 (solo la primera vez o si quieres reiniciar los datos):
    python init_database.py

Paso 2 (iniciar el servidor):
    python -m uvicorn backend.app:app --reload --port 8000

¡Y listo! Abre en tu navegador:
👉 http://localhost:8000


--------------------------------------------------------------------
OPCIÓN B: EN CUALQUIER OTRA COMPUTADORA (PROFESOR / COMPAÑERO / PC NUEVA)
--------------------------------------------------------------------
Quien descargue o clone el proyecto por primera vez debe seguir estos 4 pasos:

1. Clonar o abrir la carpeta del proyecto en una terminal:
    cd Mascoteabilidad-de-dinosaurios

2. Instalar dependencias de Python (solo una vez, tarda 10 segundos):
    pip install -r backend/requirements.txt

3. Inicializar la base de datos SQLite por separado:
    python init_database.py

4. Iniciar el servidor web:
    python -m uvicorn backend.app:app --port 8000

Luego abrir: http://localhost:8000

--------------------------------------------------------------------
✨ NUEVAS FUNCIONES Y MÓDULOS DEL PROYECTO
--------------------------------------------------------------------
- Registro con verificación de email:
  Al hacer clic en "Crear Cuenta", se envía un código de 6 dígitos que se muestra en la consola del backend y en una alerta en pantalla (Modo Simulación Académica) para poder activarla al instante.
- Recuperación de contraseña:
  Enlace "¿Olvidaste tu contraseña?" con token temporal de un solo uso.
- Panel de Gestión de Usuarios (Admin):
  Modificación de roles institucionales, altas y bajas con persistencia directa en SQLite.
- Tablero Analítico Multinivel:
  Drill-Down / Drill-Up (3 niveles: Períodos -> Hábitats -> Especies).
- Semaforización Visual:
  3 estados (Verde = Viable, Amarillo = Precaución, Rojo = Peligro letal).
- Comparador Cara a Cara (Head-to-Head):
  Enfrentamiento métrico de dos especies con ganador automático.
- Documentación de API Swagger:
  http://localhost:8000/docs
